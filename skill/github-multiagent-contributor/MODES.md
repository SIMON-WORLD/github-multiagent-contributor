# GitHub Multi-Agent Contributor — Modes

## Contributor identities
Add / remove / verify co-author identities via `scripts/build_contributors.py` (`--apply` / `--remove` / `--check`).

## Scheduled check-in (optional)
Enable `AGENT_CHECKIN_ENABLED` and configure `AGENT_CHECKIN_AUTHORS` for at most one transparent daily record with verified co-author trailers.

## Real PR collaboration (optional)
Issue → branch → PR → CI → review → merge, for real development/documentation tasks.
